# 초록마을의 네 계절

학교 수업용 생태계 이야기 게임. 마을 설정을 다섯 장으로 읽고 시작합니다. 태블릿 가로 화면에서 길을 따라 전체 지도 이동 → 장소 전환과 달력 챕터 제목 → 상황 설명 → 인물의 타자기 대화와 문장형 선택지 → 작업과 풍경 변화로 이어집니다. 지도 클릭은 가장 가까운 길에 목적지를 잡고 연결된 길의 최단 경로를 따라 걷습니다. 16개 계획에 도로 회전, 배관 끌어 끼우기, 솔 청소, 돋보기 조사, 씨앗·물·꽃 성장, 쓰레기 수거, 농약 분무, 조명 순서 기억, 손잡이 조정, 분리배출, 컵 다섯 개 쌓기, 화면 마찰로 불붙이기를 배정했습니다. 미션 완료는 계획을 실행할 준비가 끝났다는 뜻이며, 계획 자체의 생태계 영향을 바꾸지 않습니다. 예측 결과와 지도상의 결과 분류 문구는 선택 화면에 표시하지 않습니다. 실행한 뒤 이전 풍경 위로 새 풍경이 겹쳐 나타납니다. 첫 판 뒤에 앨범의 단서와 계절별 재시작을 사용할 수 있습니다.

엔딩에는 그 판에서 만든 마을 전체와 영화식 자막을 함께 표시합니다. ‘마을만 크게 보기’로 전체 지도를 확대할 수 있고, 앨범에서 다시 보면 해당 엔딩의 선택으로 지도를 복원합니다. 지도 변화는 기존 선택 기록에서 그리므로 저장 형식이나 Firebase 규칙을 변경하지 않습니다.

2026-10-07 이동·연출 수정: 모든 계절이 끝나면 실제로 고른 네 문장을 먼저 표시하고 회의로 이어집니다. 마지막의 방법 변경 선택과 E10은 유지합니다. 엔딩은 아래에서 위로 흐르는 크레딧이며, 일시 정지·배속·전체 읽기·다시 재생을 지원합니다. 작물 사진은 촬영음·플래시·인화 모양으로 보이며, `wait` 선택 기록을 가진 기기와 엔딩에서 같은 세 관찰 사진을 다시 구성합니다. 사진은 고정된 게임 그림의 관찰 구역을 재현하므로 Firebase에 큰 이미지 데이터를 추가하지 않습니다. 분리배출 물건은 현재 기존 그림을 유지하며 추후 그림 교체 대상으로 남겨 두었습니다.

공개 주소: https://green-village-ecology.pages.dev/ (2026-10-07 Cloudflare Pages 무료 배포).

배포 관리: https://dash.cloudflare.com/3375959224884e815872d29033c3ded4/pages/view/green-village-ecology

현재 공개 버전에는 전체 이동 지도, 장소별 챕터 배경과 대화, 계획별 미니게임, 실행한 뒤 남는 마을 변화, 엔딩의 전체 마을 표시가 들어 있습니다. 오리지널 BGM 3곡, 10분 간격 온라인 저장과 기존 수집 기록을 함께 사용합니다. 미니게임 배포 뒤 `index.html`, `app.mjs`, `model.mjs`, `missions.mjs`, `missions.css`가 최종 수정본과 같은 내용이며 올바른 HTML/JavaScript/CSS 형식으로 제공되는 것을 확인했습니다. GitHub에서 정규화하는 줄바꿈 차이는 제외했습니다.

지도 그림 교체 자동 배포 성공 기록: https://github.com/ajootree/green-village-ecology/actions/runs/37578495872 . 공개판에서 사진과 같은 `cut → treat → care → reuse` 조합을 실제 진행해 E08 엔딩에 네 구역의 그림과 기록이 함께 반영되는 것을 확인했습니다. `world.mjs`와 네 WebP가 로컬 최종본과 일치하며 브라우저 오류가 없었습니다.

미니게임 자동 배포 성공 기록: https://github.com/ajootree/green-village-ecology/actions/runs/37575428416 . 공개판 800×480에서 돋보기를 실제로 끌어 흔적을 찾고 기록했으며, 낙엽을 잘못 기록하면 진행되지 않고 올바른 세 흔적을 기록하면 실행 버튼이 열리는 것을 확인했습니다. 이전 화면 개편의 지도·엔딩 검증 기록: https://github.com/ajootree/green-village-ecology/actions/runs/37572945718 .

동일한 Firebase 프로젝트를 계속 사용하므로 학교 계정과 이미 온라인에 저장된 엔딩을 이관할 필요가 없습니다. 체험 모드 기록과 아직 온라인에 저장하지 않은 변경은 기존 주소의 기기에 남으므로 주소를 바꾸기 전에 기존 사이트에서 온라인 저장을 완료하세요. 기존 주소 https://green-village-ecology.vercel.app/ 는 삭제하지 않았지만 예전 버전이므로 수업 배포는 새 Pages 주소를 사용하세요.

첫 공개판은 약 2.72MB ZIP으로 직접 업로드했습니다. 이제 게임 전용 비공개 GitHub 저장소 https://github.com/ajootree/green-village-ecology 에 코드와 배포 설정을 보관합니다. `ajtr.kr` 연결은 사용자의 요청대로 나중에 진행합니다.

## GitHub 자동 배포

`.github/workflows/cloudflare-pages.yml`은 `main`의 게임 파일·검증 파일·배포 설정을 변경해 푸시하면 게임과 저장 검사를 실행하고, 통과한 경우 기존 Cloudflare Pages 프로젝트에 `dist`를 배포하도록 구성했습니다. 로컬 파일을 저장하는 것만으로 푸시되지는 않습니다. 수정 사항을 커밋하고 GitHub에 푸시하는 단계가 필요합니다. 사이트 주소와 Firebase 저장 프로젝트는 그대로 사용합니다.

현재 상태: 자동 배포 연결 완료 (2026-10-07). Cloudflare Pages 배포 전용 키를 GitHub의 암호화된 Actions secret에 등록했고 자동 배포를 활성화했습니다. 게임·저장 검사와 실제 Cloudflare 배포가 모두 통과했으며 기존 공개 주소에서 첫 화면 표시, 화면 밖 스크롤 없음, 브라우저 오류 없음을 확인했습니다. 성공 기록: https://github.com/ajootree/green-village-ecology/actions/runs/37570616893 (세 번째 실행 시도). 배포는 약 30초였으며 파일 수동 업로드가 필요하지 않습니다.

연결에는 이 Cloudflare 계정의 `Cloudflare Pages: Edit` 권한만 가진 토큰을 저장소의 암호화된 Actions secret `CLOUDFLARE_API_TOKEN`으로 등록하고, Actions variable `CLOUDFLARE_DEPLOY_ENABLED`를 `true`로 설정합니다. 토큰은 코드·공개 게임 파일에 넣지 않습니다. 배포 작업은 사이트 정적 파일만 갱신하며 Firebase 규칙이나 학생 기록을 변경하지 않습니다. 검사 기록: https://github.com/ajootree/green-village-ecology/actions

## 오리지널 배경음악

- 마을: 「초록마을 산책」, 피아노·오르골·플루트 느낌의 D장조 왈츠, 약 69초.
- 밝은 엔딩: 「우리의 다음 봄」, 피아노·현악 느낌의 D장조, 약 51초.
- 어둡거나 씁쓸한 엔딩: 「돌아오지 않는 봄」, 느린 피아노·현악 느낌의 D단조, 약 58초.
- 외부 녹음과 샘플 없이 `scripts/compose_bgm.py`로 직접 구성·합성했습니다. 음원은 CC0로 배포하며 `dist/assets/music/LICENSE.txt`에 기록했습니다. 음원 재생에 외부 API나 구독을 사용하지 않습니다.
- 상단 🔇/🔊 버튼으로 켜고 끄고, ♫ 버튼에서 음량을 조절합니다. 기본 음량은 35%이며 기기에 기억합니다. 새로 연 페이지는 항상 소리를 끈 상태로 시작합니다. 실제 태블릿에서 브라우저의 첫 터치와 기기 음량·무음 설정도 확인하세요.
- 실행 전 선택이나 계절에 따라 음악을 바꾸지 않습니다. 엔딩을 만난 뒤 분위기에 맞는 곡으로 부드럽게 전환하고, 새 모험에서는 마을 곡으로 돌아옵니다. 탭이 숨겨지면 재생을 쉬고 돌아오면 이어 재생합니다.
- 세 곡의 MP3 합계는 2,129,328바이트입니다. 음악을 켜기 전에는 음원을 요청하지 않으며, 엔딩 곡도 해당 장면에 도달했을 때 받습니다. 음악을 모두 받는 5,000명의 첫 이용은 음원만 약 10.65GB입니다.

## 계정과 저장

- Firebase 프로젝트: `green-village-ecology` (Spark, 무료). Firestore Standard, `(default)`, 서울 `asia-northeast3`.
- Firebase Authentication 이메일/비밀번호 방식. 학교·닉네임을 정규화하고 SHA-256으로 내부 로그인 주소를 만듭니다. 학생의 실제 이메일은 받지 않습니다. 비밀번호는 Firebase Authentication에서 처리하며 게임 기록 문서에 저장하지 않습니다.
- 학생이 입력하는 학교와 닉네임은 계정을 구별하기 위한 이름입니다. 학교 소속을 확인하는 인증 기능은 없습니다. 학교명은 지역까지 동일하게 입력하도록 안내하세요.
- 같은 학교·닉네임·비밀번호로 다른 기기에서도 계절 진행과 수집한 엔딩을 불러옵니다. 비밀번호 분실 시 자체 복구 기능은 현재 없습니다.
- 변경은 기기에 즉시 저장하고 온라인에는 10분 간격으로 묶어 저장합니다. 엔딩도 같은 저장 대기열에 합칩니다. 학교 계정 메뉴 또는 엔딩 화면의 저장 버튼을 누르면 즉시 저장합니다. 바뀐 내용이 없는 저장 요청은 쓰기를 발생시키지 않습니다. 실행 전 미니게임 진행은 준비 상태이므로 재접속 시 다시 준비합니다. 실행한 선택과 계절 위치는 유지됩니다.
- 기기를 바꾸거나 종료하기 전 상단 저장 상태가 ‘저장 완료’인지 확인하세요. 학교 계정 메뉴의 ‘지금 저장하기’와 ‘저장하고 로그아웃’을 사용할 수 있습니다. 작은 화면에는 상단 저장 버튼 대신 계정 메뉴를 사용합니다.
- 여러 기기에서 같은 계정을 동시에 진행하면 오래된 기록으로 덮어쓰지 않도록 충돌을 알립니다. 계정 메뉴에서 온라인 기록을 불러오세요. 수집한 엔딩은 합칩니다.
- 공유 태블릿을 위해 로그인은 브라우저 세션 동안 유지합니다. 체험 모드는 해당 기기의 기록만 이용합니다.

## 공개 파일과 데이터 보호

`dist`만 공개합니다. Firebase 웹 설정은 공개 클라이언트 식별 정보이고 관리자 키가 아닙니다. 학생 데이터는 `ecoPlayers/{본인 UID}` 한 문서에 보관합니다. 배포한 `firebase/firestore.rules`는 본인 문서 읽기/쓰기만 허용하고 다른 사람 기록, 전체 목록, 잘못된 저장 형식과 프로필 변경을 거부합니다. 다른 앱이나 기존 서비스의 데이터는 사용하지 않습니다.

지도 일러스트는 AI 생성 이미지입니다. 기본 지도 WebP는 약 698KB이며, 선택별 그림 네 묶음은 합계 2,754,252바이트입니다. 기존 지도의 해당 구역을 참조하여 같은 화풍·시점·크기로 도로, 통로, 처리 시설, 농장, 축제 물건과 연기를 그렸습니다. 지도 안의 도형·체크 표시·큰 글자 대신 그림을 사용하고, 선택 기록은 화면 밖 안내란에 표시합니다. 원본 PNG와 검수 도구는 공개 배포에서 제외합니다. 생성 문구와 그림 경로는 `art-source/README.md`에 기록했습니다. 게임 중 AI API를 호출하지 않습니다.

## 무료 운영 범위

총 이용자 5,000명 이상을 여러 학교가 나누어 이용하는 조건으로 구성했습니다. 등록 인원 자체에 5,000명 제한을 두지 않습니다. 무료 서비스의 사용량 한도는 별개이며 무제한 접속을 보장하지 않습니다.

- Firestore 무료 일일 할당량: 읽기 50,000회, 쓰기 20,000회. 거래 저장은 읽기도 발생합니다. 같은 날 장시간 이용자 수가 늘면 저장 한도에 닿을 수 있습니다.
- Firebase 신규 계정 생성은 동일 IP에서 시간당 100개 제한이 있습니다. 학교 전체가 한 외부 IP를 쓸 경우 반별 가입 시점을 나누세요.
- Cloudflare Pages의 정적 파일 요청은 무료·무제한입니다. 서버 함수는 사용하지 않습니다. 무료 직접 업로드 제한인 1,000파일/개별25MiB에 비해 게임은 22파일, 최대 파일 약 0.85MB입니다. 기존 Vercel 공개판은 이전 기록 확인용으로 남겨 두었으며 수업 배포 주소는 Cloudflare Pages입니다.
- 가짜 시간과 Firestore로 실제 저장 모듈을 검증한 2시간 연속 진행에서는 자동/마지막 저장 합계 12회였습니다. 신규 가입 한 번을 포함해 800명이 같은 날 이용하면 약 10,400회 쓰기입니다. 수동 저장 횟수, 재접속, 거래 재시도와 다른 이용자는 별도로 늘 수 있습니다. 쓰기 한도는 계속 확인해야 하며 총 이용자 5,000명과 하루 5,000명 수업은 다릅니다.
- Firebase Spark와 Cloudflare Pages 무료 구성을 사용하며 유료 요금제로 전환하지 않았습니다. 5,000명 동시 접속 부하 시험을 수행한 것은 아닙니다.

공식 근거: [Firebase 요금제](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans), [인증 제한](https://firebase.google.com/docs/auth/limits), [Cloudflare Pages 가격](https://pages.cloudflare.com/), [직접 업로드 제한](https://developers.cloudflare.com/pages/get-started/direct-upload/), [Firestore 할당량](https://firebase.google.com/docs/firestore/quotas).

## 교육 내용

도로 개발에 따른 서식지 단절, 오염원 관리와 일회성 청소의 차이, 농약과 먹이 관계·수분, 생물 다양성, 쓰레기·전기 사용, 복원의 한계와 지속적인 보전을 다룹니다. 죽은 생물이 다시 살아나지 않는 결말 등 어두운 결과도 직접적인 문장으로 표현합니다. 게임의 숫자는 실제 생태계 예측 모델이 아니며 엔딩 조건은 교육용 단순화입니다.

기존 시나리오 `../eco-scenario/초록마을의_네_계절_분기시나리오.md`와 이전 초안의 교과서·지도서 조사 기록을 계승합니다. 조사 기록에는 아이스크림 2022 개정 과학 4-2 교과서 50~53쪽 및 지도서 214~223쪽을 사용했습니다. 원문 장문이나 교과서 이미지는 공개 파일에 넣지 않았습니다.

## 확인한 동작

- 지도 그림 조화 개편 (2026-10-07): 환경을 나타내던 도형과 지도 안 큰 문구를 제거하고 지역별 그림을 연결했습니다. 256개 선택 조합의 장소/전체 지도 일치, 실행 전 변화 미노출, 저장 기록 재구성과 늦은 복원에도 기존 피해 유지 검사 통과. 네 계절의 16개 그림을 검수 화면에서 확인하고, 실제 게임에서 봄 계획 실행, 하천 기존 오염 배경, 앨범의 E08 다시 보기 및 엔딩 전체 지도를 확인했습니다. 800×480·1024×600에서 문서 스크롤 없이 표시됐고 브라우저 오류가 없었습니다. 실제 iPad/Safari는 미검증입니다.
- 장소 화면 개편 (2026-10-07): 256가지 네 계절 조합의 장소/전체 지도 일치, 실행 전 변화 미노출, 저장된 선택으로 지도 재구성, 뒤늦은 대책에도 기존 피해 유지 검사 통과. Chrome에서 네 계절을 실제 진행해 도로·처리 시설·관리 구역·컵 반납함·연기 반영, 지난 장소 재방문, 새로고침 후 이어 하기, E08/E10 수집과 엔딩별 지도 다시 보기를 확인했습니다. 800×480·1024×600에서 문서 스크롤 없이 장소 조작과 엔딩 전체 지도를 표시했습니다. 실제 iPad/Safari는 별도 확인이 필요합니다.
- 512가지 선택 조합을 검사해 10개 엔딩 모두 도달 가능함을 확인.
- 계정 식별 정규화, 학교별 계정 구별, 잘못된 기록 정리와 앨범 병합 검사 통과.
- 실제 Firebase 시험 계정 가입·로그인·저장, 잘못된 비밀번호 안내, 다른 브라우저에서 여름 위치와 봄 기록 복원 확인.
- 실제 Firestore API에서 본인 생성·읽기·갱신 허용, 다른 계정/비로그인/전체 목록/프로필 변조/잘못된 엔딩 거부 확인.
- 이전 준비 활동의 화면 검증은 미니게임 개편 이전 기록입니다. 현재 조작 검증은 다음 항목을 참고하세요.
- 미니게임 개편 (2026-10-07): 16개 계획 모두 미션 완료 가능, 잘못된 조작 거부, 미완료 실행 차단, 완료 후 추가 조작 차단 검사를 통과했습니다. Chrome에서 9종류를 실제 진행했습니다. 솔·붓 끌기, 돋보기 조사, 씨앗 끌기 후 물주기, 쓰레기 끌기, 조명 두 순서, 손잡이 맞추기, 물건 분류 후 낮 조명 끄기 및 터치 대체 조작을 확인했습니다. 잘못된 분류는 진행되지 않고 재시도 가능합니다. 800×480·1024×600에서 화면 밖 스크롤이 없고 미션 뒤 전체 지도와 E07 엔딩에 선택이 남았습니다. 실제 iPad/Safari는 별도 확인이 필요합니다.
- 영화식 엔딩, 전체 보기, 앨범, 겨울부터 재시작에서 이전 세 계절 기록 유지 확인.
- BGM: 브라우저에서 소리 켜기·끄기, 35%→30%→35% 음량 조절, 마을→E08 어두운 엔딩→새 모험의 곡 전환을 확인. 800×480에서 문서 크기 800×480 유지, 콘솔 오류 없음. 실제 iPad/Safari 기기 청취는 미검증.
- 저장 간격: `node --experimental-vm-modules qa/check-save-schedule.mjs`로 2시간 이용 시 쓰기 횟수, 동일 내용 중복 저장, 같은 시각의 저장 중 새 변경, 오프라인 뒤 로그아웃 저장, 다른 기기 기록 충돌 보호를 검증했습니다. 실제 800명 동시 부하 시험이 아닙니다.
- Cloudflare 공개판 검증 (2026-10-07): 이전 Vercel 사이트에서 시험 계정을 만들고 네 계절을 실행해 E08을 저장한 뒤, 새 Pages 사이트의 Chrome에서 같은 계정으로 E08을 복원했습니다. Pages에서 겨울부터 다시 진행해 E10을 수집하고 엔딩 화면 저장 버튼으로 온라인 저장했습니다. 별도 인앱 브라우저에서 새로고침 후 E08·E10 두 엔딩 복원을 확인했습니다. Chrome에서 공개판 BGM 켜기도 확인했습니다. 겨울 진행 위치를 저장한 뒤 별도 브라우저에서 이어 하기 복원과 로그아웃도 확인했습니다. 공개판 1280×720에서 문서 크기가 화면 크기와 같고 화면 밖 스크롤이 생기지 않았습니다. 실제 학생 계정은 사용하지 않았습니다.
- 최종 로컬 800×480에서 엔딩 화면 저장 버튼과 계정 안내, 앨범 두 페이지, E08 다시 보기, 겨울부터 재시작을 확인했습니다.
- 기존 공개 주소 로그인 후 E08·E10 두 엔딩 앨범과 겨울 진행 복원 확인. 1280×650에서 문서 크기가 화면 크기와 같고 실행 버튼이 화면 안에 있음을 확인. 두 기기 간 저장 충돌 표시와 온라인 불러오기를 통한 복구 확인.

시험 계정은 ‘시험용 초록학교’와 ‘저장 검증용 학교’에만 생성했으며 실제 학생 정보를 사용하지 않았습니다. 운영 전 교사가 한 판을 직접 진행해 문장 난이도와 수업 시간을 확인할 수 있습니다.

## 편집과 재배포

- 이야기/엔딩: `dist/model.mjs`
- 화면/조작: `dist/app.mjs`, `dist/style.css`, `dist/world.css`
- 작은 작업 미션: `dist/missions.mjs`, `dist/missions.css`
- 지도/장소 배경과 실행 후 변화: `dist/world.mjs`, `dist/assets/world/` (기존 지도 위에 해당 구역의 그림을 연결합니다). 그림 생성 기록: `art-source/README.md`.
- 그림 검수: `node qa/serve-art.cjs` → `http://127.0.0.1:8768/` (공개 배포에 포함하지 않습니다)
- 음악/소리 조절: `dist/music.mjs`, `dist/assets/music/`. 작곡 원본: `scripts/compose_bgm.py` (numpy, lameenc 1.8.1).
- 계정 연결: `dist/cloud.mjs`, `dist/firebase-config.mjs`
- 저장 권한: `firebase/firestore.rules` (Firebase 콘솔에 게시한 파일)
- 로컬 미리보기: `node server.cjs` → `http://127.0.0.1:8767/`
- 검증: `node qa/check-model.mjs`, `node qa/check-state.mjs`, `node qa/check-world.mjs`, `node qa/check-missions.mjs`. `qa/check-cloud.mjs`는 실행할 때 실제 시험 계정 두 개를 생성하므로 필요한 때만 사용합니다.
- 배포: GitHub 자동 배포 연결 후 `main`에 수정 사항을 푸시합니다. 연결 전 또는 수동 복구가 필요한 경우 `scripts/package.py`로 `green-village-ecology.zip`을 만들어 기존 Cloudflare Pages 프로젝트에 직접 업로드할 수 있습니다.
