# 공기·물·흙이 드러나는 이야기와 풍경 (2026-10-08)

## 수업 연결
교과서 『과학 4-2』(2022 개정) 50–53쪽과 지도서 214–223쪽의 인간 활동, 대기·수질·토양오염, 생태계 보전 내용을 기존 엔딩 학습 흐름 안에 연결한다. 공기·물·흙의 중요성을 시작 이야기에서 읽고, 각 주민은 현재의 현장 상황을 말한다. 선택지에는 행동만 나오며, 결과 설명과 피해 그림은 실행 뒤에 나타난다.

- 물: 작업장의 탁한 배출수와 눈에 보이는 쓰레기를 구별한다. 청소·가림막·부분 수리는 지속되는 배출을 해결하지 못한다. 시설 관리 경로도 수질 확인을 계속해야 한다.
- 흙: 농약을 **정해진 양보다 많이** 쓰는 행동을 선택 전에 명시한다. 정상적인 농약 사용 자체를 같은 피해로 취급하지 않는다. 실행 뒤 전문가가 흙에 남은 농약을 확인했다고 설명한다.
- 공기: 쓰레기를 태운 뒤 연기가 학교·광장으로 퍼지고, 대기오염으로 바깥 수업·생활이 어려워지는 상황을 보여 준다.
- 복수 원인: 가을에 과도한 농약을 쓴 뒤 비가 오면, 하천에 농장 유출수가 남는다. 여름에 작업장 시설을 고쳤어도 별도 오염원은 자동으로 해결되지 않는다.
- 서식지 파괴와 세 오염은 계속 구별한다. 끝의 복원 약속이나 캠페인이 이전 피해를 지우지 않는다.

## 그림
기존 화풍·시점에 맞춰 built-in image_gen으로 농장 피해와 농장 유출수 그림 두 장을 편집했다. 도형으로 오염 물질을 덧그리지 않았다.
- `dist/assets/world/farm-local-atlas-v4.webp`: 농약 피해 칸만 교체한 기존 네 상태 아틀라스. 축축한 흔적·고랑과 노출된 흙, 시든 작물이 보인다.
- `dist/assets/world/river-farm-runoff-v1.webp`: 밭 쪽에서 하천으로 들어오는 탁한 물. 수리한 작업장과 처리수는 유지된다. 미수리 경로에는 하천·물가 부분만 연결해 시설을 고쳤다는 잘못된 그림이 나타나지 않게 한다.
- 축제장의 기존 태우기 그림은 학교 방향 연기까지 포함하도록 표시 범위를 넓혔다.
- 하천 장면의 카메라 범위를 조정해 유출 지점과 작업장이 함께 보이게 했다.
- 원본 PNG는 `art-source/`에 보관하며 배포에 넣지 않는다. 사용하지 않는 v3 농장 WebP는 배포 폴더에서 제거했다. 최종 생성 문구는 `art-source/pollution-prompts.md`에 기록했다.

그림은 이 게임에서 정한 오염 상황을 설명하는 삽화다. 실제 물·흙의 오염 여부를 색이나 작물의 시듦만으로 판별하는 활동은 아니다. 대사에서 확인과 조사를 연결한다.

## 검수
`qa/pollution-review.html`은 실제 게임의 여름/가을/겨울 대화·미션·결과를 로컬 시험 기록으로 여는 화면이다. `qa/art-review.html`은 그림 조합 검수용이며 공개 배포에 포함하지 않는다. 기존 256개 지도 조합, 512개 엔딩·학습 조합 검사를 확장해 복수 오염원, 미실행 결과 숨김, 연기의 표시 범위와 엔딩 물고기 표시 순서를 검사한다.

Chrome에서 여름의 현재 오염 대화/행동 선택지, 가을 농약 미션의 실제 완료 → 실행 전 피해 미노출 → 이전 그림과 겹친 전환 → 토양·수질 결과 → 전체 지도와 미니 지도의 동일 변화, 겨울 대기오염 결과 → 선택 기록/마을 회의 → E06 자막/전체 지도 → 최초 수첩 자동 안내를 확인했다. 800×480에서는 여름 대화, 농약 미션·결과, 대기오염 결과 모두 문서 스크롤 없이 표시됐다. 1024×600의 지도·겨울 결과도 넘침이 없었다. 브라우저 오류·경고가 없었다. 실제 iPad/Safari는 별도 검수가 필요하다.

16개 미션, 계정별 기록 분리, 42개 이동 경로, 저장 주기 검사도 통과했다. 새 배포 그림 두 파일의 합은 632,528 bytes로, 제거한 농장 v3의 749,026 bytes보다 116,498 bytes 작다. 공개 main은 교체하지 않고 기존 작업 브랜치에 이어 저장한다.
