# 태블릿 미션과 엔딩 읽기 수정

미션 패널은 브라우저의 실제 높이에 맞추어 상단 여백을 줄이고 하단 실행 버튼을 고정한다. 발자국 조사에서는 관찰 그림과 설명을 나란히 배치하고 통로 선택은 별도 하단 행에 둔다. 중복 조작 안내는 설명 옆으로 합쳐 그림 높이를 확보한다. A·B·C 통로 버튼은 최소 44px 높이를 유지한다.

새 엔딩은 첫 재생만 흐르는 자막으로 보여 준다. 마지막 문장을 읽은 뒤 전체 글을 정지 상태로 펼치며, 제목을 화면 위에 계속 표시한다. 학생은 글 안에서 위아래로 이동할 수 있고 내 선택 돌아보기 버튼을 눌러 다음 활동으로 진행한다. 3초 뒤 자동으로 돌아보기 안내를 여는 동작은 제거했다. 앨범 팝업과 상단 엔딩 다시 보기 버튼은 모두 움직임 없이 전체 내용을 펼친다. 마을 그림은 별도 버튼으로 볼 수 있다.

확인한 내용

- 800×480 브라우저 화면에서 돋보기 손잡이 끌기, 세 지점 관찰, B 통로 선택, 완료 버튼 활성화를 확인했다. 관찰 그림 높이는 195px이며 세 선택 버튼은 높이 44px, 아래쪽 406px로 화면 안에 있다.
- 같은 화면에서 16개 미션의 패널과 페이지에 세로 넘침이 없음을 확인했다.
- 1024×600 화면의 관찰 그림 높이는 282.5px이며 통로 선택 버튼과 실행 버튼이 표시된다.
- 새 E09의 자막을 끝까지 재생한 뒤 reading-all 상태로 정지하며 팝업이나 학습 화면을 자동으로 열지 않음을 확인했다. 사용자가 돌아보기 버튼을 누르면 학습 화면이 열린다.
- 앨범 팝업의 E09 다시 보기는 제목과 전체 내용을 즉시 표시하며 변환 효과와 자동 팝업이 없다.
- 엔딩 512조합, 10개 엔딩, 16개 미션, 지도 256경로, 이동 42경로와 저장 검사 통과.

브라우저 화면 크기를 바꾸어 검수했다. 실제 iPad와 Safari 기기 검수는 별도로 필요하다.
