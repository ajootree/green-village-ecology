# 작업 중 알림 (2026-10-08)

조작법은 하단에 고정한다. 도구 집기, 잘못된 배관/분리배출/기억 순서, 다음 작업, 완료는 미션 안쪽 상단에 불투명한 토스트로 표시한다. 오답은 주황, 다음 단계와 완료는 초록 계열이며 제목과 아이콘으로도 구별한다. 문구 길이에 따라 4.2~9초 후 사라지고 “🔔 알림”으로 다시 읽는다. 알림이 도구 클릭/끌기를 막지 않는다. 다른 미션으로 이동하면 알림과 타이머를 정리한다.

모든 16개 계획에 같은 알림을 사용한다. 배관/꽃 심기/분리배출/컵 쌓기/흔적 조사에는 다음 단계도 안내한다. 기억 점검의 색 순서 표시는 도구 상단에 따로 남긴다.

검증: 16개 미션 상태 검사 통과. 실제 브라우저에서 배관 오답 → 맞는 배관 3개 → 밸브 → 완료, 자동 숨김 → 다시 보기, 기억 점검 오답/첫 라운드/다음 순서, 미션 변경 정리를 확인했다. 800×480 및 1024×600에서 토스트가 화면 안에 있고 문서 스크롤이 생기지 않는다. 기본 조작법은 알림 중에도 유지되며 콘솔 오류가 없었다. 실제 iPad/Safari는 별도 확인이 필요하다.

엔딩 활동 간소화는 학습 분류나 게임의 엔딩 조건을 변경하지 않는다. 캠페인 두 칸/편지 한 칸 완료, 공백 미완료, 이전 초안 호환, 그림에 불필요한 이전 항목이 나오지 않는 것을 검사했고 512개 학습 경로 검사가 통과했다. 브라우저에서 작성 → 카드 → 마무리 → 다시 열기 복원을 확인했다. 입력 글은 기존과 같이 이 기기에만 저장한다.
