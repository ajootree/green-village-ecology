# 엔딩 뒤 생태 학습과 보전 활동

2026-10-08. 이전 작업 브랜치의 최신 수정 96931e5434942bb7ca8f3a778409238e2e79bdda에서 이어 구현했다.

## 확인한 교과 자료

- 작업 폴더의 아이스크림미디어 2022 개정 과학 4-2 교과서 50~53쪽(PDF 페이지 52~55), 교사용 지도서 214~223쪽을 직접 읽었다.
- 핵심: 인간 활동의 오염 원인 → 공기·물·흙의 변화 → 생물의 종류·수와 서식지 변화. 보전의 필요성, 개인 실천, 사회·국가의 역할, 협력과 토의.
- 교과서의 대기·수질·토양오염과 지도서의 캠페인 실천을 엔딩 뒤 기록과 활동으로 연결했다. 교과 문장을 길게 인용하거나 교과서 이미지를 배포하지 않는다.
- 먹이 관계, 사람의 생활과 생물 관찰/농사/지역 비용은 게임 사례의 교육적 연결이다. 모든 오염이 반드시 같은 피해를 만든다는 실제 예측 모델은 아니다.

## 학습 수첩

첫 엔딩의 자막 뒤 마을 그림이 1.8초 동안 나타나고, 2.3초 뒤 수첩을 안내한다. 이후에도 완료된 엔딩에서 다시 열 수 있다. 여섯 장(전체 기록 + 다섯 주제)을 수동으로 읽는다. 선택 전에 결과를 보여 주지 않는다. 분류는 엔딩 번호가 아니라 그 판의 네 선택에서 계산한다.

- 흙: 과도한 농약의 피해 여부를 구별한다. 쓰레기가 있다는 사실만으로 측정된 토양오염이라고 단정하지 않는다.
- 공기: 무분별한 태우기에서 나온 연기를 연결한다. 태우지 않았다고 모든 대기오염이 해결되었다고 하지 않는다.
- 물: 시설 관리와 농약 유입 가능성을 함께 본다. 청소와 지속 배출 처리, 물의 겉모습과 실제 확인을 구별한다.
- 서식지: 도로 단절, 덤불/다양한 풀밭 제거, 농약의 주변 생물 영향을 구별한다. 서식지 파괴를 세 오염 중 하나로 오분류하지 않는다.
- 생활: 재사용·분리배출·절전, 일회성 청소와 다음 행사에 반복되는 부담을 구별한다.

## 노력하기

E06~E10에는 바로 가기 버튼이 있다. 다른 엔딩도 수첩에서 보전 약속을 쓸 수 있다. 작성은 미래의 행동 계획으로 기록하며 생태계 회복 점수나 새로운 엔딩을 주지 않는다. 문구/편지와 까닭, 행동, 함께할 대상, 시작 시점의 다섯 칸을 채우면 카드로 남긴다. 문장 의미를 AI나 금칙어 점수로 평가하지 않는다. 수업에서 서로 읽고 토의하도록 안내한다.

글과 초안은 별도 로컬 키에 저장하므로 다른 기기로 동기화되지 않는다. 화면에서 이를 안내하며 PNG로 받을 수 있다. 기존 Firebase 계정, 진행, 앨범의 동기화 방식은 변경하지 않는다. 편지는 실제 동물·기관에 자동 전송되지 않는다.

## 검증

512가지 선택/마지막 대책 조합의 학습 분류, 복수 오염원, 서식지 구별, 뒤늦은 대책의 피해 유지, 작성 완료 조건과 입력 길이 검사. 기존 16개 미션·512개 엔딩·256개 지도·42개 이동·저장 간격 검사 통과. Chrome에서 마지막 회의 → E09 → 자막/그림 → 첫 수첩 자동 안내 → 다섯 개념 → 캠페인 작성 → PNG 다운로드 → 새 탭에서 활동 복원 → 저어새 편지 작성/PNG 다운로드를 확인했다. 실제 iPad/Safari는 별도 확인이 필요하다.

화면 확인: 800×480·1024×600에서 수첩 여섯 장과 캠페인/세 동물 편지의 문서 넘침이 없었다. 800×480의 종합 페이지는 분야명으로 압축하고 눌러 자세히 읽는다. 작은 가로 화면의 글쓰기 다섯 칸은 두 열로 배치했다. 캠페인 및 편지 PNG 실파일을 확인했고 캠페인 그림도 시각 검수했다. 브라우저 오류가 없었다. 작업 브랜치에만 반영하며 이번 변경으로 공개 main을 교체하지 않는다.
